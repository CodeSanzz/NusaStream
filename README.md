# NusaStream 🌏

NusaStream adalah repository plugin untuk [CloudStream](https://github.com/recloudstream/cloudstream) yang menghadirkan beragam sumber tontonan dengan nuansa Nusantara. Cukup tambahkan repository ini ke aplikasi CloudStream, lalu pasang plugin yang kamu butuhkan.

## Cara Pasang
1. Buka CloudStream → **Pengaturan** → **Ekstensi**
2. Tambahkan repository dengan URL repo ini
3. Pilih dan pasang plugin yang diinginkan

## Disclaimer
Repository ini hanya menyediakan kode ekstensi. Seluruh konten berasal dari pihak ketiga dan tidak dihosting, dimiliki, maupun dikelola oleh pengembang NusaStream.
